## Что в этом репозитории

- `apps-script/Code.js` — весь код интеграции (оба потока, диагностика, журнал, почта об ошибках).
- `apps-script/appsscript.json` — манифест: таймзона Europe/Moscow, V8,
  web app `executeAs: USER_DEPLOYING`, `access: ANYONE_ANONYMOUS` (нужно, чтобы Тильда могла
  постить вебхук без авторизации).
- `apps-script/.clasp.json` — scriptId проекта (не секрет).
- Секретов в коде НЕТ: все ключи (`PARTNER_TOKEN`, `USER_TOKEN`, `TILDA_CML_*`, `COMPANY_ID`,
  `WRITEOFF_MASTER_ID`, `STORE_STORAGE_ID`, `CONTROL_SHEET_ID`) живут в Script Properties.
  `.clasprc.json` (OAuth-токен) в `.gitignore` — не коммитить никогда.

## Как обновлять код

```
clasp login --no-localhost        # в новой сессии: ссылку Ирине, она вернёт redirect-URL
cd apps-script && clasp push      # код → Apps Script
clasp deploy                      # новый deploy (URL вебхука меняется! обновить в Тильде)
```
⚠️ `clasp deploy` создаёт НОВУЮ версию с НОВЫМ URL. Если менять URL в Тильде не хочется —
обновлять существующий deployment, а не создавать новый.

## Открытые вопросы и риски

- ⚠️ **Продажа `type_id=1` с `cost=0` — создаёт ли финоперацию, НЕ проверено.**
  На боевом 23.07 подтверждали это для СПИСАНИЯ (`type_id=4`, `paid:false`, `payment`/`kkm` пусто).
  В работу по решению Ирины пошла ПРОДАЖА (`type_id=1`), чтобы засчитывалась как продажа —
  но для неё проверку не повторяли. Если продажа 0 ₽ финоперацию создаёт, выручка задвоится
  с той, что Ирина проводит статьёй дохода. Резерв — вернуться на `type_id=4`.
  Проверяется готовым эндпоинтом `?action=testOp&type_id=1&good_id=<id>` (создаёт боевую
  операцию → смотрим `paid`/`payment`; чистится через `?action=delDoc&doc=<id>`).
- ⚠️ **Диагностический `doGet` открыт наружу и гейтится захардкоженным `DIAG_SECRET_`.**
  Web app развёрнут как `ANYONE_ANONYMOUS` (иначе Тильда не сможет постить). Кто знает
  секрет и URL — может перезаписать Script Properties (`action=setup`), удалить складской
  документ (`delDoc`), создать операцию (`testOp`). Секрет лежит в коде, репозиторий приватный.
  После обкатки Потока B — удалить `setup`/`delDoc`/`testOp` или заменить секрет на
  Script Property. Помечено в коде комментарием.
- **Новые товары** в Тильде из YClients пока не создаём («создавать новые = ВЫКЛ») — в Тильде
  уже все 500. Включать отдельным решением, иначе риск дублей.
